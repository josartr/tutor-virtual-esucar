1. Introducción al Proyecto: Tutor Virtual ESUCAR

Objetivo: Facilitar y estructurar el proceso académico de los estudiantes de la Escuela de Suboficiales de Carabineros, digitalizando su progreso en los Trabajos de Título.

2. Autenticación y Validación Institucional

El primer desafío fue asegurar que el registro simule un entorno oficial. Reemplazamos iconos genéricos por la marca de la institución y fortalecimos el Single Sign-On (SSO).

// Modificación en MainActivity.kt - Login Screen
Image(
    painter = painterResource(R.drawable.institutional_header_logo),
    contentDescription = "Emblema Carabineros ESUCAR",
    modifier = Modifier.size(72.dp),
    contentScale = ContentScale.Fit
)

// Validación de dominio
fun isEmailForInstitution(email: String): Boolean {
    val domain = email.trim().lowercase().substringAfterLast("@", "")
    return domain == "esucar.cl" || domain == "carabineros.cl"
}

Martín: "En pantalla ven cómo estructuramos el inicio de sesión. Era clave que el usuario se sintiera dentro de una plataforma oficial. Por eso, integramos el emblema de la escuela."

José: "Además, a nivel lógico, aplicamos una función que valida que los correos registrados terminen obligatoriamente en dominios institucionales como '@esucar.cl' o '@carabineros.cl', dándole robustez al sistema."

4. Nuevas Herramientas: Cultura y Radio

Añadimos accesos al Museo Histórico y a la Radio de Carabineros para fomentar la identidad doctrinal del alumno.

// Agregado en StudyToolsScreen
Button(
    onClick = {
        val intent = Intent(Intent.ACTION_VIEW,
            Uri.parse("https://www.museocarabineros.cl/web/sitio"))
        if (intent.resolveActivity(context.packageManager) != null) {
            context.startActivity(intent)
        }
    }
