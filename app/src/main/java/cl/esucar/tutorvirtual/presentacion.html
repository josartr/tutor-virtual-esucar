02 · Seguridad & Persistencia Offline Diapositiva 3 / 8

SQLite Local con Derivación Criptográfica PBKDF2-SHA256

Controles Críticos en Base de Datos

  • Cero texto plano: Las claves se derivan con PBKDF2WithHmacSHA256 a 120.000 iteraciones.
  • Salt único por cuenta: 16 bytes aleatorios generados con SecureRandom.
  • Comparación segura: MessageDigest.isEqual() previene ataques de temporización (timing attacks).
  • Higiene de memoria y migraciones: Limpieza con spec.clearPassword() y esquema SQLite v6 con onUpgrade sin pérdida de sesiones.
data/LocalRepository.kt · PasswordHasher
private object PasswordHasher {
    private const val ITERATIONS = 120_000
    private const val KEY_LENGTH = 256

    fun hash(password: String, salt: String): String {
        val spec = PBEKeySpec(
            password.toCharArray(),
            Base64.decode(salt, Base64.DEFAULT),
            ITERATIONS, KEY_LENGTH
        )
        return try {
            Base64.encodeToString(
                SecretKeyFactory.getInstance("PBKDF2WithHmacSHA256")
                    .generateSecret(spec).encoded, Base64.NO_WRAP
            )
        } finally { spec.clearPassword() }
    }
}
Guion de Exposición

Martín"Al ser una herramienta offline-first para turnos sin cobertura, la autenticación completa funciona localmente en SQLite. Por eso protegimos las credenciales con estándares criptográficos reales."

José"En este bloque crítico generamos un salt aleatorio por usuario y aplicamos 120 mil iteraciones PBKDF2-SHA256. Al finalizar limpiamos el arreglo de caracteres en memoria con clearPassword() y validamos el hash en tiempo constante."

05 · Multimedia Media3 en Segundo Plano Diapositiva 6 / 8

Radio Carabineros en Vivo con MediaSessionService

Mejores Prácticas Media3 (API 35)

  • Servicio Foreground mediaPlayback: ExoPlayer vive dentro de RadioPlaybackService con WAKE_MODE_NETWORK y manejo automático de foco de audio.
  • Notificación persistente: DefaultMediaNotificationProvider muestra controles Play / Pause, metadatos (FM 98.1 / AM 820) y emblema institucional.
  • Sincronización bidireccional: MediaController conecta el ViewModel con el servicio, manteniendo sincronizada la barra MiniRadioBar y su slider de volumen.
  • Accesos rápidos: Radio en vivo, Revista Carabineros y Museo de Carabineros.
radio/RadioPlaybackService.kt
class RadioPlaybackService : MediaSessionService() {
    override fun onCreate() {
        super.onCreate()
        val provider = DefaultMediaNotificationProvider.Builder(this)
            .setChannelId(RADIO_CHANNEL_ID).setNotificationId(3001)
            .build().apply { setSmallIcon(R.drawable.ic_radio_notification) }
        setMediaNotificationProvider(provider)

        val player = ExoPlayer.Builder(this)
            .setAudioAttributes(audioAttributes, true)
            .setHandleAudioBecomingNoisy(true)
            .setWakeMode(C.WAKE_MODE_NETWORK)
            .build()

        mediaSession = MediaSession.Builder(this, player)
            .setSessionActivity(sessionActivityIntent).build()
    }
}

Intents Seguros (<queries>), WorkManager y Tests Unitarios

Ingeniería de Calidad

  • Visibilidad de paquetes: Bloque <queries> para ACTION_VIEW (HTTPS/HTTP) resuelve apertura externa de Revista y Museo en Android 11–15.
  • Recordatorios autónomos: WorkManager verifica permiso POST_NOTIFICATIONS en API 33+ y alerta sobre hitos próximos.
  • Pruebas automatizadas JUnit: Validan correos institucionales, normalización RFC, rangos policiales, formato APA 7 y avance ponderado.
  • Identidad de APK: Ícono adaptativo propio de alta resolución y compilación limpia con Lint.
